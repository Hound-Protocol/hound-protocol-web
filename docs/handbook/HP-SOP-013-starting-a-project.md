# Starting a Project
Code: HP-SOP-013 · Version 1.0 · Effective 2026-10-26 · Owner: Administration · Used by: the project lead and Administration

How a new project joins Hound Protocol. A project is a product with its own repository, team and documentation. Ideas are welcome on Discord; a project starts when Administration agrees the team is ready.

## 1. Decide
Write a short proposal (one page): what it is, who it is for, who builds it, what it needs from other people's property, and whether the repository is public or private. The project lead accepts it as a decision record (ADR).

## 2. Checklist
- [ ] **Repository** created in the organization. Private if the project is proprietary.
- [ ] **Branch protection and checks** on `main` ([HP-POL-004](HP-POL-004-security-policy.md) section 4).
- [ ] **License** chosen and written down, or "all rights reserved" stated ([HP-POL-008](HP-POL-008-licensing-and-attribution.md)).
- [ ] **Third-party rights** reviewed: does the project use anything that belongs to someone else? Write its rules ([HP-POL-003](HP-POL-003-third-party-rights.md)).
- [ ] **AI rules** accepted ([HP-POL-002](HP-POL-002-ai-use-policy.md)), plus any stricter project rule.
- [ ] **Project documentation** started, with the files in [HP-GDE-021](HP-GDE-021-project-documentation.md).
- [ ] **Name and brand** checked against other people's marks; project brand kept apart from the Hound Protocol brand ([Brand](../brand.md)).
- [ ] **Discord** category for the project ([HP-SOP-008](HP-SOP-008-discord-administration.md)).
- [ ] **Backups** include the repository ([HP-SOP-009](HP-SOP-009-backup-and-restore.md)).
- [ ] **Projects page** updated, with a link to the project's documentation, or a note that it is private.

## 3. Open to others
Staff seats fill once there is a playable prototype. Contracts open when the project lead says so ([HP-SOP-010](HP-SOP-010-publishing-contracts.md)).

## 4. Name it in public
Add the project to [Projects](../projects.md) with its state: planned, in development, released or retired.
