# Contributor Quick Start
Code: HP-GDE-003 · Version 2.0 · Effective 2026-10-26 · Owner: Development · For: new contributors and contractors, in any project

> **Project setup is in the project.** This guide covers what is the same everywhere. Build tools, tests and folder layout are in the project's own documentation (see [Projects](../projects.md)).

## 1. Read first (20 minutes)
- Not sure where you fit? [Can I Contribute?](HP-GDE-017-can-i-contribute.md)
- [Contributor Policy](HP-POL-001-contributor-policy.md) and [AI Use Policy](HP-POL-002-ai-use-policy.md), with the practical side in [Working with AI Assistants](HP-GDE-018-working-with-ai-assistants.md)
- [Third-Party Rights Policy](HP-POL-003-third-party-rights.md): no protected files, no copied code
- [Departments and grades](../departments.md): how the organization is built
- New to GitHub or Discord? [GitHub Basics](HP-GDE-014-github-basics.md) and the [Discord Member Guide](HP-GDE-008-discord-members.md)

## 2. Set up (30 minutes)
1. GitHub account with **two-factor authentication** ([HP-GDE-010](HP-GDE-010-account-security.md)).
2. Install git and an editor. The project's documents list anything else (languages, engines, build tools).
3. Fork the project's repository and clone your fork.
4. Run the project's checks locally. The project's contributing file lists the commands.

## 3. Take a contract
1. Open the project's contract board. Pick a contract whose dependencies are done. Difficulty tells you what to expect. Easy is a good first one.
2. Sign in and press **Claim** on the card, or comment `/claim` on the issue. Others may claim it too: say hello and split the work.
3. Read its goal, deliverable and acceptance criteria. Ask questions on the issue, not in private.

## 4. Deliver
1. Branch: `git switch -c area/short-topic`.
2. Commit with sign-off: `git commit -s -m "Short, clear message"`.
3. Push and open a pull request. Fill in the template, including AI assistance.
4. Fix what review asks for. When Quality approves, it merges and your record is issued.

## 5. Writing style
Plain English, short sentences, active voice. Facts with sources and confidence. See [HP-GDE-005](HP-GDE-005-documentation-style.md).
