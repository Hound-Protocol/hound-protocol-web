# Start here
Status: Current · Updated: 2026-10-26 · Applies to: everyone

This is the Hound Protocol Documentation. It holds what applies to the whole organization. Each project keeps its own documentation next to its code.

## Two zones
| Zone | What it holds | Look and feel |
|---|---|---|
| **Library** | Who we are, how we are organized, decisions, brand and project pointers | Case files in drawers |
| **Handbook** | Policies, procedures and guides: the rules and the how-to | Controlled sheets, printable on A4 |

## How to find things
- **Search.** Press `Ctrl K` or `/`. Type words; every word must match. Switch between **Name** (file number and title) and **Content** (the full text).
- **Keyboard.** Arrow keys move between files, `Enter` opens one, `Esc` clears the search.
- **Links.** Every document has a **Copy link** button. The address is stable: `docs.html#governance`.
- **Print.** The **Print** button gives a clean A4 page without the menus.

## File numbers
| Prefix | Meaning |
|---|---|
| ORG | Organization documents |
| ADR | Decision records. A changed decision gets a new record; old ones are never deleted |
| PRJ | Project pointers |
| HP-POL | Policy: a rule everyone must follow |
| HP-SOP | Procedure: step-by-step |
| HP-GDE | Guide: how-to help for an audience |

## Every document says its status
A document starts with its code, version, effective date, owner and audience. If something is not done, the document says so. "Planned for 0.1" beats silence (HP-GDE-005).

## Fix something
Every document has **Suggest an edit**, which opens the file on GitHub. Writing rules are in the Documentation Style Guide (HP-GDE-005). The Handbook copies come from the Joint Operations repository, so edit them there.
