# Start here
Status: Current · Updated: 2026-10-26 · Applies to: everyone

This is the Hound Protocol Documentation. It holds what applies to the whole organization and to every project under it. Each project keeps its own documents in its own documentation, next to its code.

## What belongs here, and what does not
| Here | In the project's own documentation |
|---|---|
| Who we are, how we are organized, who decides what | The project's design, plans and research |
| Rules for everyone: conduct, security, AI use, licensing, quality | Rules that exist only because of that project (a game's legal limits, a platform's terms) |
| Procedures every project follows: contracts, reviews, releases, bans | Build steps, tools and test plans for that project |
| Guides for joining and contributing | Player guides and how-tos for that project |
| Brand of Hound Protocol | Brand of a single project |

A document that names one project only does not belong here. Find it through [Projects](projects.md).

## Two zones
| Zone | What it holds | Look and feel |
|---|---|---|
| **Library** | Who we are, how we work, decisions, brand, and where each project keeps its documents | Case files in drawers |
| **Handbook** | Policies, procedures and guides: the rules and the how-to | Controlled sheets, printable on A4 |

## Find things
- **Search.** Press `Ctrl K` or `/`. Every word you type must match. **Name** searches file numbers and titles; **Content** searches the full text.
- **Keyboard.** Arrow keys move between files, `Enter` opens one, `Esc` clears the search.
- **Links.** Every document has a **Copy link** button. Addresses are stable: `docs.html#governance`.
- **Print.** **Print** gives a clean A4 page without menus.

## File numbers
| Prefix | Meaning |
|---|---|
| ORI | Orientation |
| ORG | Organization documents |
| ADR | Decision records. A changed decision gets a new record; old ones are never deleted |
| HP-POL | Policy: a rule everyone must follow |
| HP-SOP | Procedure: step by step |
| HP-GDE | Guide: how-to help for an audience |

## Every document says its status
A document opens with its code, version, effective date, owner and audience. If something is not done, the document says so ([HP-GDE-005](handbook/HP-GDE-005-documentation-style.md)).

## Fix something
Every document has **Suggest an edit**, which opens the file on GitHub. The files live in the `hound-protocol-web` repository, folder `docs/`. How to start a project's own documentation: [HP-GDE-021](handbook/HP-GDE-021-project-documentation.md).
